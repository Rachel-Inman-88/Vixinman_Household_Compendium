# 03 — EVERY NM ELECTRIC UTILITY: INTERCONNECTION CONTACTS & PROCESSES
*Compiled July 2026. Contact data for cooperatives verified against the NM PRC company directory (prc.nm.gov — state source) in July 2026; process details for the five northern utilities carried from the June 2026 Utility Forms doc with corrections. All PRC-jurisdictional utilities follow NMPRC Rule 17.9.568 (interconnection) and 17.9.570 (net metering credits): application → utility design approval BEFORE construction → build → CID/AHJ final electrical inspection → utility inspection → written authorization before parallel operation. Fees, forms, and pre-screening steps differ per utility. Municipal utilities (Farmington, Los Alamos, Gallup, Aztec, Raton, T or C, Springer town) are NOT under NMPRC — each has its own rules.*

**Universal application package:** inverter spec sheet (UL 1741 / IEEE 1547-2018), one-line diagram (show utility-accessible lockable load-break disconnect where required), site diagram, customer (not contractor) signature.
