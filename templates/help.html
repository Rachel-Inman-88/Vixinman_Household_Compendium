1. Signing in & your account

↑ contents

Tutorial — set up self-service password reset

  1. Click your name (top right) → My account.
  2. Under Security questions, pick 3 questions and type answers only you know.
  3. Confirm with your current password and Save. Answers are stored scrambled and are case-sensitive.
I forgot my password — how do I get back in?

On the sign-in page click Forgot your password?, enter your username, and answer the 2 (randomly chosen) security questions you enrolled. You then set a new password yourself — no admin needed. If you never set up questions, ask an admin to reset it from your profile.

Why can't I answer my security questions?

Too many wrong answers notifies the household's admins, who can reset your password directly from your profile.

I got signed out on my own — why?

Sessions end after 12 hours of inactivity (the clock resets on each action). Just sign in again.

2. The idea backlog

↑ contents

Tutorial — add an idea and start it as a project

  1. From 🗄 Databases → Backlog, add an idea — a repair, build, or certification not started yet.
  2. Optionally set who proposed it, a target/someday date, a rough budget estimate, and a custom reminder date.
  3. When you're ready, open the idea and click 🚀 Start as a project — it becomes a real project you fill in from there.
What happens to an idea I'm not doing anymore?

Mark it Abandoned from the idea's page — it stays on record (not deleted) and can be moved back to the backlog later if you change your mind.

How do backlog reminders work?

Once a month, everyone with a login gets a single notification if anything is still sitting in the backlog. You can also set a custom reminder date on a specific idea for a one-time nudge on top of that.

3. Projects & the pipeline

↑ contents

Stages: Planning → Prep → In Progress → Wrap-up → Done (plus Abandoned), each with its own exit criteria. Creating, editing, cancelling, and reopening a project needs the Manage projects permission (Parent/Assistant by default, not Child) — everyone can still view any project.

Tutorial — advance a project

  1. Open the project. The Pipeline stage panel shows what's needed to advance.
  2. Use Advance to … when ready — a stage advances once its own tasks are done; nothing auto-advances on its own.
  3. To change the stage directly, click the ✎ next to the stage name.

Tutorial — cancel (and reopen) a project

  1. On the project, open 🚫 Cancel this project, type a reason (required), and confirm. The project is marked Abandoned.
  2. Its open tasks stop showing in My Tasks / the board / the Work Bag, and everyone who was involved is notified.
  3. To bring it back, use ↩ Reopen project — it returns to the exact stage it was at.

Tutorial — brainstorm a project with 🧠 Plan

  1. Open the project and switch to its 🧠 Plan tab.
  2. Chat about how to finish the project — the assistant already knows its Category/Subcategory, open tasks, and recent field notes, so it can tailor suggestions accordingly.
  3. When it suggests a concrete next step, click ➕ Add to project to actually add it as a task (tagged to the project's current stage, so it counts toward advancing it) — nothing is added unless you click. Click 💾 Save as project note on any reply worth keeping.
Does the Plan chat save conversations, or does it forget them?

Each project keeps its own Plan conversation — reopen the tab any time to pick up where you left off, alongside whatever tasks/notes you chose to keep from it.

Can the AI change my tasks or notes on its own?

No — like the 💬 Assistant, the Plan chat is read-only. It can only suggest; you decide what actually gets added by clicking ➕ or 💾 yourself.

Where do cancelled projects go?

Nowhere is deleted. An admin can review them under 🗄 Databases → Closed projects (reason, who/when, contract) with one-click Reopen, alongside completed projects.

What are Category and Subcategory for a project?

Every project picks a Category — Home Improvement (Building, Landscaping, Gardening, Maintenance & Repair) or Personal Improvement (Education, Health, Habit, Relationship, Misc) — and a matching Subcategory. The Subcategory list narrows automatically to match whichever Category you pick.

Who gets told when a project moves to a new stage?

Every household member with a login gets an inbox notification. Your copy clears the first time you open it (or open the project).

4. Requirements engine (certs, permits & recurring paperwork)

↑ contents {% if help_unlocked('rules') %}

Tutorial — add or edit a rule

  1. Go to 🗄 Databases → Requirements Editor.
  2. Project-triggered: pick the project field + value that triggers it, a category, and a label; add links, phone, notes, and the verbatim source text if it's a prerequisite rule. Standalone: check "Recurring, not tied to a project" instead and set who it's assigned to and how often it repeats — for internal household obligations like taxes or homeschool registration.
  3. Set the Verification callout dropdown (none / ⚠ Verify / ⚠ Unverified) to flag anything to confirm — you can add or remove it any time. Cost, time, and maintenance notes are optional and purely informational.
Where do the requirements show up on a project?

On the project's Requirements tab (Permits lead, with an inline upload slot each), and browsable in the read-only Requirements Library filtered by project type. Standalone recurring requirements show on the Requirements Editor and on the dashboard's "My requirements" card instead, since they aren't tied to a project.

What does the ⚠ Verify chip mean?

It's a reminder to confirm that item before relying on it (Unverified = couldn't confirm online). It's an editable field per rule now, not automatic.

5. Tasks & the field Work Bag

↑ contents

Tutorial — do field work from the Work Bag

  1. Open 🎒 Work Bag (works offline). Tap a project to see its field tasks, hours, receipts, and notes.
  2. Finish a task with ✓ Submit as done and enter the time it took.
  3. Photo steps open a take / review / submit screen — at least one photo is required.
  4. An admin approves the submission on the Approvals page.
Can I log a receipt or a note from the field?

Yes — snap a receipt (date, total, vendor, category) and it's filed as a paid expense; the 📝 Project notes box saves timestamped notes for the office.

My tasks list looks empty for a project I know exists.

Cancelled (Abandoned) projects are hidden from tasks. Also, the field views show only on-site work; office/scheduling steps live on your dashboard.

5b. Boards — stand-alone to-dos

↑ contents

Boards (📋 in the top bar) are to-dos not tied to a project — clean the bathroom, call a vendor, etc.

Tutorial — create a to-do and send it to a teammate

  1. Open ✅ To-do → 📋 Boards and use ＋ New board — give it a title, optionally a person to send it to, a priority, and a due date.
  2. Open the board to log time (hours + date + note, with a running total), add notes as it progresses, and change its status.
  3. To hand it off, use Send this to-do to and pick a teammate — they get a notification.
Where do I see to-dos sent to me?

On 📋 Boards, the Mine filter shows to-dos assigned to you; you also get a 🔔 notification when one is sent to you.

Can I update an older board's notes later?

Yes — open the board any time and add another note; the log keeps every entry with author and timestamp.

5c. Chores — recurring household to-dos

↑ contents

🔁 Chores are repeating to-dos — dishes, trash, laundry — assigned to a household member on a repeating schedule, different from Boards' one-off to-dos.

Tutorial — add a chore

  1. Open ✅ To-do → 🔁 Chores and use ＋ New chore — give it a title, who it's assigned to, and how often it repeats.
  2. Mark it ✓ Done when finished — a recurring chore reschedules itself for the next occurrence automatically.
Where do I see chores assigned to me?

Your dashboard's 🔁 My chores card, and the Mine filter on the Chores page.

5d. Appointments — dates & scheduling

↑ contents

📅 Appointments track one-off or recurring dates and times — doctor visits, service calls, anything that belongs on a calendar.

Tutorial — add an appointment

  1. Open ✅ To-do → 📅 Appointments and use ＋ New appointment — set a title, date, optional time, who it's for, and optionally a repeating schedule.
  2. Link it to a Contact (e.g. the dentist's office) if it's with someone in your Contacts list — or start it directly from a contact's ＋ Add appointment quick-link.
  3. Mark it ✓ Done once it's passed, or let a recurring one roll to its next date automatically.
Can I see my appointments in an outside calendar app?

Yes — your dashboard's 📅 Upcoming appointments card links to your personal calendar feed (.ics), which you can subscribe to from Google Calendar, Apple Calendar, or Outlook alongside your chores and requirement due dates.

6. Billing

↑ contents {% if help_unlocked('finance') %}

Tutorial — track a project's budget

  1. On the project's 💵 Billing tab, set the contract total (a plain dollar figure — no pricing/margin calculator behind it).
  2. Record deposits, receipts, and expenses as income/expense ledger entries as the project goes.
  3. The Billing tab totals up contract, collected, outstanding, and expenses so you can see where the budget stands.
Can everyone see a project's contract total?

No — money-in-flight figures and the Billing tab need the Manage finances permission (Parent by default). A Child doesn't see them at all, not even a locked/read-only view.

6b. Household Budget — expenses, income & receipts

↑ contents {% if help_unlocked('budget-help') %}

💵 Budget tracks whole-household money — groceries, utilities, subscriptions — separate from a project's own Billing tab, which stays project-only. Both need the Manage finances permission (Parent by default) — a Child doesn't see either at all.

Tutorial — set a budget and log an expense

  1. Open 🏠 Household → 💵 Budget and add a category with a monthly target amount.
  2. Log income/expenses as they happen — category, amount, date, optionally a Contact (who you paid) and a photo of the receipt.
  3. The month's summary shows actual spend against each category's target, with a bar that turns red once you're over.
Does this replace a project's Billing tab?

No — a project's contract, deposits, and expenses stay exactly as they were on its own Billing tab. Household Budget is a separate, whole-house ledger for everyday spending that isn't tied to any one project.

6c. Loans

↑ contents {% if help_unlocked('loans-help') %}

💳 Loans tracks named loan accounts (a car loan, a mortgage) — each has its own running balance, computed from its entry ledger rather than typed in as a single number.

Tutorial — set up a loan and record a payment

  1. Open 🏠 Household → 💳 Loans and add an account — name, lender, original amount, and interest rate are all optional except the name.
  2. Open the account and record entries as they happen: a Payment reduces the balance, a Charge increases it (a fee, or an additional draw). A statement photo/PDF is optional.
  3. The balance updates automatically — it's always original amount + charges − payments, computed live.
Can I attach a statement to a payment?

Yes — each entry has an optional photo/PDF attachment, same as a Budget receipt.

6e. Contacts — people & organizations outside the household

↑ contents

🧰 Contacts (under 🗄 Databases) covers both individual helpers (a plumber, a babysitter) and organizations you deal with (a subscription service, a co-op, a utility) — each with its own relevant fields.

Tutorial — add an organization

  1. Open 🧰 Contacts → ＋ New contact and set Type to Organization.
  2. Fill in the organization-specific fields — website, account number, contact person, and a renewal date if it's a subscription.
  3. Use the ＋ Add appointment link on the contact's row to schedule something with them directly.
Can I still add a plain person, like a handyman?

Yes — set Type to Person instead; you get the original, simpler field set (name, phone, specialty, notes).

7. Inventory & Wishlist

↑ contents

Tutorial — add an item

  1. Open 🗄 Databases → Inventory and click ＋ New item (or ＋ New tool / ＋ New vehicle).
  2. Category is free text — type whatever makes sense (Pantry, Tools, Electronics, ...); a dropdown suggests categories you've already used.
  3. Set the Quantity you have on hand, and optionally where you bought it, a cost, and purchase/manual links.
Where does inventory come from?

The household's inventory starts empty — add items, tools, and vehicles as you actually acquire them. Each item just tracks how many you have; there's no stock ledger or procurement workflow behind it.

Tutorial — ask for more of something (Wishlist)

  1. From 📦 Inventory, click the 🎁 next to any item to ask for more of it — or use the 🎁 Wishlist button to add something new, optionally linked to a Project or a Contact.
  2. It sits Pending until a parent/admin Approves or Rejects it.
Does approving a wishlist item buy it or add it to Inventory automatically?

No — approving is just the household's "go ahead" signal. Someone still adds it to Inventory (and logs the expense in 💵 Budget, if you're tracking that) once it's actually purchased.

Whose wishlist is it?

Everyone has their own list; the Mine / All filter switches between your list and the whole household's. A parent can add something to a child's list directly by picking them under "For".

8. People, roles & permissions

↑ contents {% if help_unlocked('people') %}

Tutorial — add a household member

  1. Add them under 🏠 Household → 👨‍👩‍👧 Family (role, and a login if they need one).
  2. Tick Admin on their profile if they should manage household members/accounts, rules, catalog, and view the log.
What's the difference between Parent, Child, and Assistant?

Each role now comes with a starting set of permissions: Parent and Assistant both get everything except Delete, and Child gets none of the named permissions by default (day-to-day features like Tasks, Boards, Chores, Appointments, and adding a Wishlist item still work for everyone regardless). Admin is a separate flag, set explicitly per person on their profile, independent of role.

Assistant is different from Parent in one important way: it's meant for an AI agent's own account. An Assistant can see everything a Parent can, but every change it tries to make is captured as a draft on the 🗒 Drafts page instead of happening right away — see below.

How are permissions granted?

Admins have full access except Delete, which always needs an explicit grant even for admins. Everyone else starts with their role's default bundle (above) and can be given more — or have something unchecked — individually on the Access page. Changing someone's role only ever adds their new role's defaults; it never removes a permission they already had.

What is the 🗒 Drafts page?

Anything an Assistant-role account tries to write — a new project, a rule, an inventory item, a household member, a budget or project transaction (including a receipt or document upload), or an approve/reject decision on a Wishlist item or Work Bag submission — lands here first, never straight into the real data. Open 🏠 Household → 🗒 Drafts to review each one: Approve applies it for real (any attached file moves into normal storage), or Discard throws it away (any attached file is deleted). Parent and Admin actions are never drafted — this only applies to a signed-in Assistant.

Why can't my child see the Budget page or a project's Billing tab?

Household finances are hidden entirely from anyone without the Manage finances permission — not just locked to editing, like most other tools. A Child has none of it by default, so the Budget page, the Billing tab, the dashboard's money tiles, and the 💬 Assistant/🧠 Plan chat's answers about contract totals are all unavailable to them. An admin can grant it individually on the Access page if wanted.

Why does this Help page show 🔒 locked sections for some people?

A Help section about a tool you don't have access to (Requirements Editor, Billing, Household Budget, this section, and the Admin section) shows a locked placeholder instead of its tutorial. The See full FAQ permission (help.full_access) bypasses this and shows everything — Parent and Assistant get it by default, Child doesn't; an admin can grant it individually on the Access page.

9. Notifications

↑ contents

Your 🔔 Notifications inbox lives under ✅ To-do (the unread count shows right on the To-do dropdown). You'll get notifications for every pipeline turnover, project cancellations you were involved in, chore/requirement reminders, and security alerts. Opening a notification clears it for you.

A notification disappeared — where did it go?

They clear once accessed (by opening the notification or the project it points to). Use Clear all on the inbox to empty it.

10. For admins

↑ contents {% if help_unlocked('managers') %}
  • 🔧 Admin → Log: the audit log of every change (who/what/when), with passwords redacted.
  • 🔧 Admin → Trash: deleted items (an admin restores or purges). Deletes are blocked if data is in use.
  • 🔧 Admin → Access: grant per-person tool access.
  • 🗄 Databases → Closed projects: review cancelled + completed projects; reopen a cancelled project.
  • Household overview (on the dashboard): pipeline counts, attention row, and the Wrap-up worklist are visible to Parent/Assistant; the money-in-flight tiles and Payments table need the Manage finances permission. A Child gets a personal 🗓 My schedule widget instead of the household overview.
How do we back up the data?

Everything lives in job_creator.db with uploaded files in the uploads/ folder — back up both together. In the desktop app that's your personal Compendium folder.
